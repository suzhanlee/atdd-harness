# Epic 로드맵

## 구현 순서

```
Epic 1 (상품 조회) ─────┐
                        ├─→ Epic 3 (단일 상품 직접 구매) ─┐
Epic 2 (장바구니 관리) ─┘                                 │
                                                          ├─→ Epic 4 (장바구니 구매)
                                                          │
                                        ←── 로직 재사용 ──┘
```

## 병렬 가능성

Epic 1과 Epic 2는 **병렬 개발 가능** (서로 독립적)

```
[팀원 A] Epic 1 → Epic 3 → Epic 4
[팀원 B] Epic 2 ─────────→ (Epic 4에서 통합)
```

## 상세 일정

| 순서 | Epic | 제목 | 의존성 | 예상 소요 | 마일스톤 |
|------|------|------|--------|----------|----------|
| 1 | Epic 1 | 상품 조회 | - | 1h | M1 |
| 2 | Epic 2 | 장바구니 관리 | - | 1h | M1 (병렬) |
| 3 | Epic 3 | 단일 상품 직접 구매 | - | 1.5h | M2 |
| 4 | Epic 4 | 장바구니 구매 | Epic 2, 3 | 1h | M3 |

## 마일스톤

- **M1** (2h): Epic 1, 2 완료 → 상품 조회 + 장바구니 기능 사용 가능
- **M2** (3.5h): Epic 3 완료 → 단일 상품 직접 구매 가능
- **M3** (4.5h): Epic 4 완료 → **전체 기능 완료 (MVP)**

## 각 Epic별 워크플로우

각 Epic은 다음 ATDD 워크플로우를 따름:

```
/validate → /adr → /redteam → /design → /redteam-design → /compound → /gherkin → /tdd → /refactor → /verify
```

## Epic 4 통합 시 주의사항

Epic 4는 Epic 3의 주문 로직을 재사용하므로:
- Epic 3 완료 후 코드 구조 파악 필요
- 데드락 방지를 위한 Lock 획득 순서 통일 (상품 ID 오름차순)
- 트랜잭션 내에서 장바구니 비우기 처리
