## 추가된 예외 케이스 (Completeness 개선)

### 구매 관련 예외

| 예외 상황 | 처리 방식 |
|-----------|-----------|
| 네트워크 타임아웃 | 최대 3회 재시도, 지수 백오프 (1s → 2s → 4s) |
| 영수증 검증 실패 | 사용자에게 "구매 확인 실패, 고객센터 문의" 메시지 표시 |
| Apple API 장애 | 사용자에게 "일시적 오류, 잠시 후 재시도" 안내, 로그 기록 |

### Webhook 관련 예외

| 예외 상황 | 처리 방식 |
|-----------|-----------|
| JWS 서명 검증 실패 | 요청 거부, 보안 로그 기록 |
| 중복 Webhook 수신 | 멱등성 키(transactionId)로 중복 처리 방지 |
| Webhook 처리 실패 | HTTP 500 응답 (Apple이 재시도), DLQ(Dead Letter Queue) 저장 |

### 업그레이드/환불 관련 예외

| 예외 상황 | 처리 방식 |
|-----------|-----------|
| 업그레이드 도중 환불 발생 | 환불 이벤트 우선 처리, 업그레이드 트랜잭션 롤백 |
| 활성 구독 없이 환불 Webhook 수신 | 로그 기록 후 무시 (이미 만료된 구독) |

## 추가된 비기능 요구사항 (구체화)

### 성능

| 항목 | 목표 |
|------|------|
| API 응답 시간 | 95% 요청 200ms 이내 |
| Webhook 처리 시간 | 500ms 이내 (Apple 재시도 방지) |
| 동시 요청 처리 | 100 TPS |

### 신뢰성

| 항목 | 정책 |
|------|------|
| 재시도 정책 | 최대 3회, 지수 백오프 |
| 멱등성 | 모든 상태 변경 API에 멱등성 키 적용 |
| DLQ | 처리 실패 Webhook은 DLQ에 7일간 보관 |

## 추가된 기술 스택

| 항목 | 선정 | 이유 |
|------|------|------|
| JWS 검증 라이브러리 | nimbus-jose-jwt | Apple JWS 검증 지원 |
| Apple 공개키 캐싱 | Redis (선택) 또는 In-Memory | 로테이션 대응, 24시간 캐시 |

## S2S Notification V2 이벤트 타입

| 이벤트 타입 | 설명 | 처리 |
|-------------|------|------|
| SUBSCRIBED | 신규 구독 | 구독 생성 |
| DID_RENEW | 갱신 성공 | 구독 기간 연장 |
| DID_FAIL_TO_RENEW | 갱신 실패 | 유예 기간 진입 또는 만료 |
| DID_CHANGE_RENEWAL_STATUS | 갱신 상태 변경 | 갱신 취소 여부 기록 |
| EXPIRED | 구독 만료 | 권한 회수 |
| GRACE_PERIOD_EXPIRED | 유예 기간 만료 | 권한 회수 |
| OFFER_REDEEMED | 프로모션 코드 사용 | 구독 생성/연장 |
| PRICE_CHANGE | 가격 변경 | 사용자 알림 |
| REFUND | 환불 | 권한 즉시 회수 |
| REFUND_DECLINED | 환불 거절 | 로그 기록 |
| RENEWAL_EXTENDED | 갱신 연장 | 구독 기간 연장 |
| REVOKE | 가족 공유 취소 | 권한 회수 |
| CONSUMPTION_REQUEST | 소비 요청 | (비갱신형) 처리 |
